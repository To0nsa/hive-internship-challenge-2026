# SuperCell coding challenge 2025

This is my submission for the SuperCell coding challenge 2025. The player controls a character that can move horizontally, jump, dash and cast spells to defeat enemies and avoid obstacles. The camera is scrolling so dont waste time, a big lava wave is coming! The game has a scoring system based on survival time and collectibles (you can collect them with an icebolt too).

## Controls

move: WASD
jump: SPACE
dash: MOUSE WHEEL CLICK
cast spell: MOUSE LEFT CLICK

## Build instructions

```bash
cmake -B build
cmake --build build
./build/bin/runner
```
